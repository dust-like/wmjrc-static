电脑装机必备

电脑软件 季若尘 8年前 (2018-11-29) 579次浏览 已收录 0个评论 扫描二维码

后台回复：电脑必备 或今天的日期 1130 获取下载

 

压缩软件：bandizip

 

界面简洁美观友好，该有的功能一个不少，最为关键的是没有广告和各种捆绑软件

 

浏览器：百分浏览器、360 极速浏览器

 

相较于谷歌浏览器，百分浏览器占用资源更少，鼠标手势操作更方便

 

360 极速浏览器（注意是极速浏览器，不是安全浏览器）不仅支持 chrome 上的各种扩展，最主要的是可以不用科学上网登录账号同步数据

 

杀毒软件：火绒安全

静默无弹窗，平时就安静的呆在右下角，只有发现病毒和可疑操作，或者更新病毒库时才会提醒一下

 

当然，如果你能忍受其它安全管家的各种广告弹窗的话，也可以用其它的，前几天我装了几天 360，貌似它们的开机加速还有点用，真是玄学

 

另外只要每次东西都尽量在官网下载安装，感染病毒的机会是很小的

 

卸载软件：WiseProgramUninstaller

这款卸载软件除了卸载软件之外还能清除残留的文件、文件夹和注册表项，可以极大减少垃圾文件的产生量

 

看图软件：honeyview

 

这款软件和 bandizip 是一个公司出的，同样的简洁迅速，支持各种格式，还能配置快捷键，设置适合自己的看图方式

 

下载软件：第三方百度网盘、迅雷极速版

百度网盘我之前为大家推荐了几款可以不限速下载的第三方网盘，可以看下这几篇文章：

不限速下载百度网盘

手机端高速下载百度网盘推荐

再推荐一个电脑端高速下载百度网盘软件

 

迅雷为大家准备的是无广告，登陆就是会员的破解版

 

 

输入法：手心输入法

输入法这东西还是要看个人习惯来，习惯用哪个就用哪个，我个人比较推荐手心输入法，没有任何广告弹窗，当然就是词库备份做的有点差，可以本地导入导出

 

屏幕录制软件：EV 录屏、screen to gif

这两款软件中 screen to gif 是完全免费的，但只能录制 gif

 

ev 录屏完全版是要收费的，但免费版已经很良心了：无限制录制时间、无水印，光这两点已经超过绝大多数录屏软件了

 

文件搜索工具：Everything

 

这是款专门搜索电脑中储存的文件的工具，只要安装加载好后，搜索任何文件都是秒出结果，比 windows 自己的文件搜索快的不是一点半点

 

文件预览工具：Quicklook

 

这款软件可以在不打开文件的情况下，直接选中文件按空格即可预览文件内容，和 mac os 的文件预览功能相似，对于体积大的 word、exel、ppt 等文件极其适合

 

这款工具可以直接在 windows 应用商店搜索下载

 

quicklook 貌似没有专门的官网，我找到了它在 github 上的项目地址，有安装版和免安装版两个版本可供选择

 

 

最近感冒，这几天都是头昏脑胀，还有几个软件下次再推荐吧
